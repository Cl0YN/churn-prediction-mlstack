Customer Churn Prediction

Проект по предсказанию оттока клиентов с использованием моделей машинного обучения.

Описание

Проект посвящен разработке модели для предсказания оттока клиентов на основе исторических данных. В проекте используются различные алгоритмы машинного обучения, такие как CatBoost, XGBoost и LightGBM, а также техника стекинга для улучшения точности предсказаний.

Цели проекта

Основная цель проекта — разработать точную модель предсказания оттока клиентов, которая поможет бизнесу принимать проактивные меры для удержания клиентов.

Установка





Клонируйте репозиторий:

git clone https://github.com/your_username/customer-churn-prediction.git



Перейдите в каталог проекта:

cd customer-churn-prediction



Установите зависимости:

pip install -r requirements.txt



Поместите данные в каталог data/ (например, Telco_customer_churn.xlsx).

Использование





Запустите основной скрипт:

python main.py



Входные данные: файл Excel с данными о клиентах.



Выходные результаты: предсказания оттока клиентов и оценка модели.
