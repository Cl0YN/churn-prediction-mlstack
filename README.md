# 💼 Churn Prediction: Boosting Models + Optuna

Проект по предсказанию оттока клиентов с помощью ансамблевых моделей (CatBoost, LightGBM, XGBoost) и автоматического подбора гиперпараметров с использованием Optuna. Включает предобработку, балансировку классов, построение пайплайнов и оценку по бизнес-метрикам.

---

## 📌 Цель проекта

Разработать и сравнить несколько моделей машинного обучения для задачи бинарной классификации — предсказания, уйдёт ли клиент, на основе табличных данных.

---

## 🧠 Используемые модели

- 📦 **CatBoostClassifier**
- 🌿 **LightGBMClassifier**
- ❌ **XGBoostClassifier**

Для каждой модели:
- построен `Pipeline` с препроцессингом,
- выполнен подбор гиперпараметров с помощью `Optuna`,
- проведена оценка на валидационной выборке по метрикам: `accuracy`, `precision`, `recall`, `f1-score`, `ROC-AUC`.

Клонируйте репозиторий:

git clone https://github.com/your_username/customer-churn-prediction.git



Перейдите в каталог проекта:

cd customer-churn-prediction



Установите зависимости:

pip install -r requirements.txt



Поместите данные в каталог data/ (например, Telco_customer_churn.xlsx).

Использование





Запустите основной скрипт:

python main.py



Входные данные: файл Excel с данными о клиентах.



Выходные результаты: предсказания оттока клиентов и оценка модели.
